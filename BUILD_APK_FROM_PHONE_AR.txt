طريقة تجهيز APK من الهاتف باستخدام GitHub Actions:
1) أنشئ حساباً مجانياً في GitHub إذا لم يكن لديك حساب.
2) أنشئ مستودعاً جديداً (New repository) باسم VENTRA-Native واجعله Private أو Public.
3) ارفع محتويات هذا المجلد إلى المستودع مع الحفاظ على المسارات، خصوصاً .github/workflows/build-apk.yml.
4) افتح تبويب Actions في المستودع، واختر Build VENTRA Android APK، ثم Run workflow.
5) انتظر انتهاء البناء. إذا نجح، افتح تشغيل workflow ثم نزّل Artifact باسم VENTRA-debug-APK.
6) فك ضغط artifact على الهاتف، ثم افتح app-debug.apk للتثبيت.
ملاحظات:
- هذا المسار يبني نسخة Debug للتجربة، وليس نسخة موقعة للنشر التجاري.
- البناء قد يفشل إذا كان في كود التطبيق خطأ؛ عندها يجب إصلاح سجل الخطأ قبل إعادة المحاولة.
- هذا المشروع أولي، وليس مكتملاً تجارياً. اختبره ولا تستخدمه لحسابات حساسة قبل مراجعة الدقة والنسخ الاحتياطي.
