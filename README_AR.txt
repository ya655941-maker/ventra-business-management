VENTRA Native Android — نسخة أولية أصلية

هذه بداية إعادة بناء VENTRA كتطبيق Android أصلي باستخدام Kotlin وJetpack Compose وSQLite محلي.
لا يستخدم المشروع WebView أو HTML أو متصفحاً، ولا يطلب صلاحية الإنترنت في AndroidManifest.

الموجود حالياً:
- واجهة Android أصلية ذهبية وعربية.
- قاعدة SQLite محلية على الجهاز.
- شاشة رئيسية ومؤشرات مبيعات ومشتريات ومصروفات وصافي حركة.
- إضافة منتجات وتسجيل مبالغ المبيعات والمشتريات والمصروفات.
- قائمة مخزون وسجل عمليات وتقارير أولية.

ما لم يكتمل بعد:
- لم يتم بناء APK أو اختبار تثبيته على هاتف حقيقي في هذه البيئة.
- لم تُنقل بعد جميع تفاصيل النسخة السابقة (العملاء والموردون والديون والتعديلات التفصيلية للمخزون).
- لا توجد سحابة أو مزامنة أو نسخ احتياطي تلقائي في هذه النسخة الأولية.
- لا تعتبر نسخة جاهزة للنشر التجاري قبل استكمال الوظائف واختبار الحسابات والنسخ الاحتياطي.

طريقة البناء: افتح هذا المجلد في Android Studio حديث، ثم اختر Build > Build APK(s).
يتطلب تنزيل Gradle ومكتبات Android أول مرة، وهذا لا يعني أن التطبيق نفسه يحتاج الإنترنت أثناء الاستخدام.
